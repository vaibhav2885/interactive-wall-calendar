# 🗓️ interactive-wall-calendar - Manage your time with visual ease

[![](https://img.shields.io/badge/Download_Calendar-Blue?style=for-the-badge)](https://github.com/vaibhav2885/interactive-wall-calendar)

This tool provides a wall-style calendar for your computer. You add notes, select date ranges, and track your schedule. It saves your data automatically to your browser. You can switch between light and dark modes to suit your eyes. The design adapts to your screen size.

## ⚙️ System Requirements

This software works on computers running Windows 10 or Windows 11. You need a modern web browser like Chrome, Edge, or Firefox to view the calendar. The file size is small and uses minimal memory. Ensure you have at least 50 MB of free storage space. 

## 🚀 Setting up the application

You do not need to install complex software. After you extract the files, follow these instructions:

1. Locate the file named index.html in the folder.
2. Double-click the file. 
3. Your web browser opens the calendar.
4. You see a full-month view on your screen.

If the browser does not open the link, right-click the file and choose Open With. Select your preferred web browser from the list.

## 📅 Using the calendar features

The interface shows a grid of dates. You interact with the calendar by clicking on specific days.

### Selecting dates
Click a start date and an end date to highlight a range. This feature helps you plan trips or project deadlines. The calendar highlights the selected days in a different color.

### Adding notes
Click any day to open a note box. Type your tasks or events in this box. Press the save button to keep the information. The calendar stores your notes inside your browser memory. You do not need an account or cloud storage to keep your notes.

### Switching themes
Find the toggle button located in the top corner of the screen. Click this to flip between light mode and dark mode. Dark mode reduces glare if you work in dim rooms.

### Responsive design
The calendar adjusts to your window size. If you reduce the window size, the calendar layout shifts to fit the available space. You can view it on small monitors or large desktop displays.

## 💾 Saving and data management

The application uses local storage to keep your notes safe between sessions. As long as you use the same browser on your computer, your notes remain in place. 

If you clear your browser cache, the application removes your notes. Export your important information to a text file if you plan to clear your browser data. 

## 🛠️ Troubleshooting common issues

If you encounter problems, check these solutions:

*   **Calendar does not load:** Check if your browser is updated. Older versions of browsers might not support modern web features.
*   **Notes disappear:** Ensure that your browser settings allow local data storage. Private or Incognito mode prevents the browser from saving your notes.
*   **Performance is slow:** Close unused browser tabs. The application requires very few resources, but other programs might slow down your system.
*   **Display looks wrong:** Refresh the page by pressing F5 on your keyboard. This fixes most layout errors.

## 💡 Frequently asked questions

**Do I need an internet connection?**
No. Once you download the folder, the application runs entirely on your machine. You do not need to connect to the internet to view or edit your notes.

**Can I sync notes to my phone?**
This version stores data only on the computer where you run the tool. For remote access, move the folder to a shared drive or a USB stick.

**Is my data private?**
Yes. Since the data stays on your hard drive, no one else accesses your notes. You control all the information entered into the system.

**How do I delete my notes?**
Click clear data or delete the specific note entries within each date box. You can also clear your browser history to reset the calendar.

**Does this software track my activity?**
No. This tool contains no trackers. It does not monitor your clicks or your habits.
